# Шаблон проекта для работы с Claude Code

Каркас репозитория, в котором человек и Claude Code работают по одному порядку:
требования — в спеках, работа — по задачам, находки записываются сразу, проверки — в CI. Не привязан к языку: стек подставляется при первом заходе.

## Начать новый проект

```
gh repo create <имя> --private --template NikonFlex/agent-project-template --clone
cd <имя>
claude            # и в чате: /bootstrap
```

`/bootstrap` расспросит, что строим, заполнит места `{{…}}`, уберёт задачи самого шаблона,
подставит линтер и тесты стека и заведёт первую задачу. Дальше в каждом новом чате — `/catchup`.

Нужны: `git`, `gh` (вошедший в аккаунт: `gh auth login`), `python3` с `pyyaml`
(`pip install -r tools/requirements.txt`) — на нём написаны скрипты процесса, даже если
проект на другом языке; `node` — для проверки копипасты.

## Что внутри

| Путь | Зачем |
|---|---|
| `CLAUDE.md` | правила работы — Claude Code читает при каждом запуске |
| `.claude/settings.json` | `.env` не читается; закрытие задач, удаление репо, force-push — с подтверждения |
| `.claude/hooks/task-reminder.sh` | перед каждым сообщением напоминает: сначала задача |
| `.claude/commands/` | `/task` — задачи на диске, `/journal` — журнал и уроки |
| `.claude/skills/` | `/bootstrap` — первый заход, `/catchup` — где остановились |
| `docs/SPEC-DRIVEN.md` | порядок «входящие → спеки → дельты» |
| `docs/incoming/` | присланные документы как есть + `index.yaml` |
| `specs/` | единственный источник требований |
| `docs/tasks/` | копия задач GitHub; низ файла — заметки агента между сессиями |
| `docs/journal/` | журнал эпизодов и уроки (`INSIGHTS.md` уже засеян) |
| `docs/decisions.md`, `docs/dev-plan.md` | почему так выбрали; как строим |
| `tools/backlog.py` | GitHub Issues ↔ `docs/tasks/`: sync, review, resume, new, comment |
| `tools/spec_check.py` | проверки входящих и спек (в CI), с самопроверкой |
| `.github/workflows/check.yml` | CI: копипаста, самопроверки, спеки; линтер и тесты — под стек |

## Как идёт работа

```
документ от людей → docs/incoming/ (как есть) → дельта в specs/
просьба хозяина → задача (docs/tasks/draft → backlog.py new) → ветка 12-имя → код по спеке
находки по ходу → низ файла задачи; общее → docs/*.md; выбор → docs/decisions.md
урок → /journal → INSIGHTS.md (читается перед нетривиальной работой)
```

## Улучшать шаблон

Правило, которое прижилось в проекте, переносится сюда отдельной задачей в этом
репозитории. В проектах, уже созданных из шаблона, его правят руками.
