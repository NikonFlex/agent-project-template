Тяжёлая проверка за день: запускается вручную вечером (`/nightly-audit`) или по расписанию
`bb automation`. Днём поток не тормозит.

## Фаза 1 — без модели (`python3 tools/nightly_audit.py`)

По коммитам/PR за день гоняет полный `pytest` + глубокий `Hypothesis` + сохранённые
`Playwright E2E` + `CRAP` по изменённым функциям + `mutmut 3` по изменённым файлам ядра +
`import-linter` + `sh tools/check.sh`, складывает компактный отчёт `tmp/nightly-report.json`.
Самопроверка — `python3 tools/nightly_audit.py --selftest`.

## Фаза 2 — сильная модель-аудитор (`gemini-4-neon`, независимая от дневного Codex)

Днём планы пишет `gpt-6.2-sol`, код — `deepseek-flash`; ночью аудитором идёт **`gemini-4-neon`**
(другое семейство, чтобы не делить общие слепые пятна), а Исследователями гипотез — `deepseek-flash`.

**Область аудита — только основная логика приложения и её спеки:** каталоги приложения,
рабочие конфиги `config/` (кроме `config/bb_*.json` и `config/arena/`), `openspec/specs/` и
связанные `tests/`. Инфраструктуру разработки (`tools/`, включая Арену, `docs/tasks/`,
`docs/journal/`, `.agents/`, `.claude/`, `.cursor/`, `.github/`) ночной аудитор не ревьюит;
если за 24 часа менялась только инфраструктура, `tools/nightly_automation.py` делает тихий пропуск.

Аудитор читает отчёт + дневной дифф по области приложения и делает:

1. Гипотезное код-ревью по дневным PR (навык `pr-review`: Ревьюер → отсев `jev_fact_check` →
   Исследователи → только подтверждённые находки с `файл:строка` и снятые подозрения). Если в PR
   или задаче сохранён `reviewId` приёмки `bb-jev v2`, сначала вызывает `jev_review_status` —
   проверяет `freshness` (`current`/`stale`) и вердикты по `R1..Rn`.
2. Аудит тестов: соответствие `openspec/specs/`, лишние/хрупкие по CRAP, «пустые» по `mutmut`.
3. `clean-contour-check` по дневному диффу.
4. **Аудит спек (`openspec/specs/`):** перечитывает спеки, затронутые за день (и смежные), и
   выносит в утренний дайджест:
   - лишнее / наверченное (переусложнения, дубли, детали реализации внутри спеки);
   - недоразобранное / дыры (пропущенные сбои, граничные случаи, переходы состояний);
   - рассинхрон «спека ↔ код ↔ тесты» и тихие «улучшайзинги» без запроса.
   Молча спеки ночью не правит — только список конкретных предложений в дайджест.

## Безопасный выход

Без авто-мержа в `main`. Бесспорные мелкие фиксы — отдельная ветка `nightly/<YYYY-MM-DD>` с
зелёным `sh tools/check.sh`; спорное и расхождения со спекой — утренний дайджест в `bb` /
Telegram (Telegram — только по слову хозяина).

## Автоматизация bb

Скрипт `tools/nightly_automation.py` (script mode): за 24 часа не было коммитов — тихий
пропуск (последняя строка `{"wakeAgent": false}`); были — запускает фазу 1 и печатает путь
отчёта. Проверка — `python3 tools/nightly_automation.py --selftest`. Постоянное расписание
создаётся отдельно, по авторизации (`bb automation create --cron …`).
