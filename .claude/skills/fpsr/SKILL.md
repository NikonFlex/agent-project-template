FPSR — мера среды, а не модели (`docs/WHY.md`). Файлы не менять: результат — хозяину.

1. `python3 tools/backlog.py sync` — копия задач могла устареть.
2. `python3 tools/fpsr.py` — доля и список задач с «нет» и причиной.
3. Причины «нет» разложить по видам: **противоречие** (две версии правды), **дыра** (знания
   нет в репо), **неясная цель** («Готово, когда» не проверяется), **другое**.
4. По каждой причине проверить, закрыта ли она уже: исправлен ли источник, который она
   называет (`git log -S`, сам файл). Незакрытые — главное в ответе.

## Как отвечать

```
**FPSR:** 0.70 (7 из 10).
**Причины «нет»:** противоречия — 2, дыры — 1 (по строке: задача — что — закрыто ли).
**Что исправить в среде:** 1–3 пункта, с файлом.
```

Несколько незакрытых противоречий или дыр в одном месте — предложить `/contradictions`.
Задач с разделом «Первый промпт» нет — так и сказать: считать пока нечего.
