Спека — канон: сжимать её можно только после «да» хозяина. Порядок — `docs/SPEC-DRIVEN.md`,
шаг 4; почему так — `docs/WHY.md`.

## 1. Аудит

`python3 tools/backlog.py sync` (не прошёл — работать по копии на диске и назвать дату
снимка из `docs/tasks/INDEX.md`), потом `python3 tools/spec_audit.py` — по каждой спеке
«в порядке» или «пора сжать» (пороги — `tools/spec_audit.json`), а под «пора сжать» — почему:
по каждому превышенному признаку чем он мешает и где в спеке (задачи и строки, цепочки по
датам, закрытые вопросы), и прогноз — сколько пометок уйдёт и какие останутся. Показать
хозяину только спеки «пора сжать», объяснения — как их выдал скрипт, со ссылками на строки
спеки; своими словами можно добавить, что это за пункты. Спросить «сжимаем?» — и ждать.
Нет таких спек — так и сказать, на этом всё.

## 2. Сжатие — только после «да»

Задача по правилу 5, ветка по её номеру. Для каждой спеки:

1. Копия до правки: `cp specs/<домен>.md <scratchpad>/<домен>.before.md`.
2. Переписать «по состоянию на дату» — **убрать только пометки, формулировки не трогать**:
   - дельты по закрытым задачам — целиком, какого бы возраста ни были: возраст нужен только
     аудиту, чтобы решить «пора»; история остаётся в файле задачи и в отчёте. Цепочка дельт
     на пункте — остаётся последняя, если её задача открыта, иначе ни одной;
   - в «Источники:» — документы со статусом `superseded` / `rejected`;
   - в «Открыто» — вопросы с «подтвердил»: ответ уже стоит в правилах.
   - **Остаются:** `DECISION <дата>` без подтверждения (живой вопрос хозяину), «подтвердил»
     в правилах, дельты по открытым задачам, весь остальной «Открыто».
   - В шапку — строка `> Сжата <дата>, история — docs/journal/spec-<домен>-<дата>.md.`
3. Отчёт `docs/journal/spec-<домен>-<дата>.md`: каждая убранная пометка дословно — пункт
   спеки, пометка, задача или документ; убранные источники и вопросы. Ничего не теряется:
   история уходит из рабочего текста, но не из репо.
4. Проверить: `python3 tools/spec_audit.py --compare <копия> specs/<домен>.md` — «смысл тот
   же»; `python3 tools/spec_check.py` проходит; `spec_audit.py` для спеки — «в порядке».
   Расхождение в `--compare` — откатить свою правку пункта, а не подгонять.
5. PR со ссылкой на отчёт; хозяин смотрит дифф.
