# Спеки и входящие

Загружается, когда Claude читает или правит спеку или входящий документ. Полный порядок —
`docs/SPEC-DRIVEN.md`; здесь — то, что нельзя забыть.

1. Требования — только из `specs/`. Входящий документ не правится и сам канон не меняет.
2. Новый документ: файл в `docs/incoming/` как получен, запись в `index.yaml` с `sha256`,
   статус `incoming → reviewed → distilled | rejected | superseded`.
3. Спека: в шапке `Статус`, `Источники:`, `Владелец дельт`; разделы «Сущности», «Правила»,
   «Критерии приёмки», непустой «## Открыто». Сущность объявлена ровно в одной спеке.
4. Изменение — дельтой в самой спеке, с датой и основанием: номер задачи и/или входящий
   документ — `*(дельта 06.10, <префикс>#7, incoming/ТЗ v2.md §3 — было «…»)*`.
   Подтверждено хозяином — `*(подтвердил <имя> <дата>)*`; решение Claude — `DECISION <дата>`.
5. Расхождение сначала разобрать самому; хозяину — только развилки про деньги, сроки,
   обещания наружу, одним пакетом с вариантом по умолчанию.
6. Спека не хранит состояние задач: `#12` можно, «сделано» рядом — нельзя.
7. Код не расходится со спекой молча: неполна — сначала дельта или вопрос в «Открыто».

Проверка — `python3 tools/spec_check.py`.
