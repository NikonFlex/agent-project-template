# Файл задачи

Загружается, когда Claude читает или правит файл задачи. Когда что делать с задачами —
`CLAUDE.md`, «Задачи»; устройство и образцы — `docs/examples/tasks/README.md`.

- Файл делится меткой — копировать посимвольно, не набирать:
  `<!-- ↓↓↓ ниже наше: скрипт эту часть не трогает ↓↓↓ -->`
  Выше метки — копия из GitHub, `sync` её перезаписывает: туда не писать.
- Низ: «Чем возобновлять» (первый шаг для следующей сессии), «Что установлено» (проверенное,
  с файлом и датой), «Что опровергнуто», «Тупики», «Ход работы», «Что осталось»
  (недоделанное — раздел появляется, когда оно есть).
- Черновик `draft-<имя>.md`: первая строка `# Название`, строка `Milestone: <имя>`, если
  задача входит в milestone, дальше что сделать и «Готово, когда».
- Находка по существующей задаче — в низ её файла, а не в новую задачу.
