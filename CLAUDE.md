## Только для Claude Code

Общие правила — в `AGENTS.md` выше: его же читают Codex и Cursor. Здесь — то, что есть
только у Claude Code.

- `/catchup` — в новом чате: где остановились, первый шаг.
- `/bootstrap` — первый заход в проекте, созданном из шаблона.
- `/task` — задачи: sync, обзор, продолжить, завести. `/journal` — запись в журнал.
- Хук `.claude/hooks/task-reminder.sh` перед каждым сообщением хозяина напоминает про
  правило 5: к середине сессии правило из файла забывается, напоминание приходит каждый раз.
- `.claude/settings.json`: `.env` не читается; закрытие задачи, удаление репозитория и
  force-push — только с подтверждения.
