## Описание из трекера

Раздел 19 `sdd-process.md`. Разработчики с разными средами — возвращаем Codex и Cursor (отменяет tpl#2).

Что сделать:

1. `AGENTS.md` — правила до первого действия; `CLAUDE.md` подключает его; Cursor — `.cursor/rules/`. Процедуры — отдельными документами; случаи, из которых выросли правила, — отдельным файлом.
2. Сторожа: общие скрипты `.agents/guards/`, тонкие входы на среду: GitHub-запись без «да», прод, PR без «Локального повтора», push без квитанции, секреты, закрывающие слова, проверки перед коммитом.
3. Правила хода работы: ход заканчивается отчётом; лучший вариант агент объявляет и делает; вопрос — только о приказе или необратимом.
4. Прибор бюджета постоянного контекста (на основе `context_check.py`).

Готово, когда:

- `--selftest` каждого сторожа отказывает на своём входе;
- одна команда печатает состояние обвязки и запускает все контрольные случаи без сети;
- форматы хуков Codex и Cursor сверены с документацией `[проверено]`.
