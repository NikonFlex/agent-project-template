## Описание из трекера

Без сценария — проверка репозитория, поведения продукта не меняет.

Сторож запрещает читать `.env`, но ключ, вписанный в код или конфиг, проходит в коммит; ruff (S105) ловит только часть.

Что сделать:

1. Найти готовое (правило 1): gitleaks — живость, лицензия, как ставится без Node/Docker (бинарь, версия закреплена).
2. Хук `pre-commit`: проверка индекса (`gitleaks git --staged` или что даёт текущая версия); CI — по коммитам PR.
3. Ложные срабатывания — файл исключений в репо; образцы ключей в самопроверках (`backlog.py` сито) не должны ломать проверку.
4. `harness.py` показывает, что gitleaks стоит.

Готово, когда:

- коммит с подложенным ключом (`AKIA…`, `sk-…`) останавливается хуком и красит CI;
- `sh tools/check.sh` и CI зелёные на текущем репо.
