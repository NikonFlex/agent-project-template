# SDD 5. Задача, коммит и закрытие по процессу SDD

Milestone: SDD

Разделы 10, 12, 13 («Слияние»), 16 `sdd-process.md`.

Что сделать:

1. Низ файла задачи со строкой «Локальный повтор»; `backlog.py` и образцы.
2. `git ticket <номер>`, хук `commit-msg`, проверка всех коммитов ветки в CI; хуки в `templates/githooks/`.
3. `Implements <префикс>#<номер>` в PR; запрет close/fix/resolve остаётся.
4. Закрытие: три отметки (локально / dev / прод), сводка из пяти пунктов, статус требований ✅; что делать с «Первым промптом» и FPSR.
5. Приёмка чужих задач — описание и навык.
6. Worktree на задачу (`agent/<имя>`) — в правилах.

Готово, когда:

- `--selftest` `commit-msg` и проверки CI падает на коммите без номера;
- `backlog.py --selftest` зелёный, `review` показывает задачи без «Локального повтора»;
- в правилах и образцах только `Implements`.
