**Что Claude Code читает в проекте** `[проверено: claude-directory.md, 06.10]`:

| Путь | Что | Когда |
|---|---|---|
| `CLAUDE.md` (или `.claude/CLAUDE.md`) | инструкции | каждую сессию целиком |
| `CLAUDE.local.md` | личное к проекту, не в git | каждую сессию |
| `.claude/rules/*.md` | правила по темам; с `paths:` — только для подходящих файлов | без `paths` — при старте; с `paths` — при Read/Write/Edit подходящего файла |
| `.claude/settings.json` | permissions, hooks, env, модель | при старте |
| `.claude/settings.local.json` | личные переопределения, не в git | при старте |
| `.claude/skills/<имя>/SKILL.md` | навык: `/имя` или сам по описанию | описание — всегда, тело — по вызову |
| `.claude/commands/*.md` | то же, одним файлом («same mechanism as skills») | по вызову |
| `.claude/agents/*.md` | субагент: свой промпт, инструменты, модель, память | по вызову `Agent` |
| `.claude/agent-memory/<имя>/` | память субагента с `memory: project` | у субагента |
| `.claude/output-styles/*.md` | стиль ответов | по выбору `/output-style` |
| `.claude/workflows/*.js` | сохранённые workflow, `/имя` | по вызову |
| `.mcp.json` (корень) | MCP-серверы команды | при старте |
| `.worktreeinclude` (корень) | gitignored-файлы, копируемые в новые worktree | при создании worktree |
