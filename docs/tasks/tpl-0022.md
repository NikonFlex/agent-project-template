## Описание из трекера

При переводе GenFacade на шаблон (NikonFlex/GenFacade, gf#74, PR #75) и в gf#76 (PR #77)
скрипты шаблона пришлось доработать. Перенести сюда, когда PR в GenFacade слиты:

1. `tools/spec_check.py` — ловить состояние задачи и после слова «задача»: «ab#7, задача
   закрыта» (`TASK_WORD` с обеих сторон ссылки); самопроверка +3 случая (это, сущность
   объявлена дважды, `distilled_into` на несуществующую спеку).
2. `tools/context_check.py` — `bases` (короткие пути внутри пакета), `skip_docs` (журнал
   решений, обзоры чужих репозиториев), `ignore_patterns` (DOI), маски `.gitignore` через
   fnmatch, слэш в конце `ignore_paths` не мешает; самопроверка на каждое.
3. `tools/check.sh` — `python3 -m pytest` вместо `pytest`: в worktree команда `pytest` берёт
   editable-пакет из другой папки.
4. `tools/spec_audit.py` (gf#76) — под «пора сжать» объяснение: чем мешает признак, строки
   и задачи, цепочки по датам, прогноз «уйдёт / останется»; дельты по всему тексту, а не
   построчно; навык `/spec-audit` показывает объяснения.

Готово, когда:

- четыре доработки здесь, `sh tools/check.sh` проходит;
- самопроверка каждого скрипта краснеет на подложенной поломке каждой доработки;
- в `docs/journal/INSIGHTS.md` — урок про `python -m pytest` в worktree.
