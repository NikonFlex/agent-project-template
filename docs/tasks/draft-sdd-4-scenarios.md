# SDD 4. Сценарии проверки, записи прогонов, статус требований

Milestone: SDD

Разделы 11, 14, 15 `sdd-process.md`. Стек шаблон не знает: в шаблоне — процесс и общие части, стенд и выкладку подключает `/bootstrap`.

Что сделать:

1. Формат сценария (JSON, поле «проверяет требования») и раннер `tools/scenario.py`: шаги `http`, `wait`, `stub`, `container`; ожидания; перечни видов объявлены один раз; режимы `replay`/`record`/`live`.
2. Контрольный сценарий с невыполнимым ожиданием в `check.sh`.
3. Запись прогона `openspec/runs/*.json` и квитанция (хеш дерева кода, режим, исход).
4. Таблица требований (✅ 🟡 🚚 🔁 ❌ ⚪), сводка; прибор: требование в таблице один раз.
5. Перенос статусов из записей прогона (без флага — показать, с флагом — править; локальная запись не меняет).

Готово, когда:

- контрольный сценарий красный внутри раннера, `check.sh` зелёный;
- `--selftest` переноса: зелёная → ✅ с пометкой; красная → 🟡; локальная — без изменений;
- раннер на примере против локальной http-заглушки проходит и падает при испорченном ожидании.
