1. `tools/commit_check.py`: ссылкой на задачу считать только подвал `Implements <префикс>#N`;

   (`.codex/rules`) — то же.

   становится).
4. `tools/backlog.py`: задача, закрытая как «не будем делать» (`not_planned`), не считается
   сделанной.

Готово, когда:
