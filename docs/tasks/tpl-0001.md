## Описание из трекера

Перенести из GenFacade (диплом) то, как устроена работа с агентами, в шаблон
GitHub-репозитория, из которого начинается любой новый проект.

Что войдёт:
- `AGENTS.md` (+ `CLAUDE.md` со ссылкой) — общие правила: сначала готовое, факты проверяем,
  записываем сразу, сначала задача, параллелить; проверка, ключи, код; места под проект.
- `.claude/` — настройки (запрет `.env`, переспрос на опасное), хук-напоминание про задачу,
  команды `/task`, `/journal`, навыки `catchup` и `bootstrap` (первый заход в новом проекте).
- `docs/SPEC-DRIVEN.md`, `docs/incoming/`, `specs/`, `docs/journal/` (INSIGHTS засеян
  общими уроками), `docs/decisions.md`, `docs/README.md`, `docs/dev-plan.md`.
- `tools/backlog.py`, `tools/spec_check.py` (префикс задач из `.backlog.json`).
- CI: самопроверки скриптов, спеки, jscpd; линтер и тесты — место под язык.

Готово, когда:
- репозиторий помечен как template, `gh repo create x --template …` даёт рабочую копию;
- в копии `python3 tools/backlog.py --selftest` и `python3 tools/spec_check.py` проходят,
  у `spec_check` есть самопроверка, которая падает на подложенном нарушении;
- CI на GitHub зелёный;
- навык `bootstrap` описывает первый заход: вопросы владельцу, заполнение мест `{{…}}`,
  уборка задач самого шаблона, стек.
