## Рабочие заметки по задачам

Здесь — тематическая база знаний. Рабочие заметки по конкретным задачам живут
отдельно, в [tasks/](tasks/): по файлу на задачу GitHub, низ файла не трогается
синхронизацией. Индекс — `tasks/INDEX.md`, обзор застрявшего —
`python3 tools/backlog.py review`. Правила — раздел «Задачи» в [../CLAUDE.md](../CLAUDE.md).

Граница с [decisions.md](decisions.md): в низу задачи — ход конкретной работы,
в журнале решений — выбор, который пережил задачу.

## Как помечать факты

Каждое содержательное утверждение — с пометкой достоверности:

- `[проверено]` — открыли первоисточник, видели сами (указать, чем проверяли)
- `[не проверено]` — со слов, из описания, из чужого пересказа

Утверждение без пометки считается непроверенным.
