## 06.10.2026 — хук перед коммитом блокировал команды без коммита

Делали хук `PreToolUse` с `if: "Bash(git commit*)"`, который гоняет проверки перед коммитом
(tpl#8). Первый пробный коммит после правки `settings.json` прошёл без хука — настройки
подхватились не сразу. Следующая команда — `git reset … && rm … && … ${PIPESTATUS[0]}` —
была заблокирована хуком, хотя коммита в ней нет: по документации на `$VAR` и `$()` шаблон
длиннее имени команды запускает хук всегда. Красное дерево блокировало бы любую команду с
`$`. Исправили: хук сам смотрит текст команды (`claude_hooks.py is-commit`).

Урок: фильтр `if` у хуков приблизительный — решение «моя ли это команда» хук принимает сам.

## 07.10.2026 — в задачу ушёл пустой комментарий

Сливая PR #15, одной командой спрятал заметки в stash, переключился на ветку с `2>/dev/null`
и отправил `comment 14`. Checkout не прошёл — на `main` лежал неотслеживаемый `tpl-0014.md`,
который создал `sync` при заведении другой задачи, — и `comment` ушёл из этой копии с пустым
низом: в #14 попала заготовка «_Проверенное — …_». Удалил комментарий, отправил верный из ветки.

Урок: не глушить ошибки шагов, после которых идёт запись наружу; перед `comment` и `new`
проверять ветку и файл.
