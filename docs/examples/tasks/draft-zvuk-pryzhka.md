# Звук прыжка

Milestone: Демо

Короткий звук при каждом прыжке; у второго прыжка — выше тоном.

Готово, когда:
- звук есть у первого и у второго прыжка;
- основной тон второго выше первого на 20–40 %;
- при паузе звук не играет.

Датчик: основной тон звука каждого прыжка, Гц — скрипт `tools/pitch.py` печатает его для
записи уровня 1.
