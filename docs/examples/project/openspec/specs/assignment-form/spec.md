# Форма назначения

## Purpose
Тип: экран. Форма, на которой автор назначает тренажёр сотруднику: выбор сотрудника, режима и
срока. Назначение объявляет спека `assignment`.

## Тексты

| Текст | Где стоит | Источник |
|---|---|---|
| «Назначить» | кнопка сохранения | ТЗ ASN01 (стр. 5) |
| «Выберите сотрудника» | подсказка пустого поля | ТЗ ASN01 (стр. 5) |

## Requirements

### Requirement: Сохранение без сотрудника
Система MUST держать кнопку «Назначить» недоступной, пока не выбран сотрудник.

**Источник:** ТЗ ASN01 (стр. 5)

#### Scenario: Сотрудник не выбран
- GIVEN автор открыл форму назначения и не выбрал сотрудника
- WHEN он смотрит на кнопку «Назначить»
- THEN кнопка недоступна, в поле сотрудника стоит текст «Выберите сотрудника»
