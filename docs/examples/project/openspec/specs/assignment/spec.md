# Назначение

## Purpose
Тип: сущность. Назначение тренажёра сотруднику: режим, срок, попытки и состояния. Сотрудника
объявляет спека `employee`, форму назначения — спека `assignment-form`.

## Сущности

### Назначение

| Поле | Значение | Источник |
|---|---|---|
| режим | «Научить» \| «Проверить навык» | ТЗ ASN03 (стр. 7) |
| срок | дата, необязательно | ТЗ ASN04 (стр. 8) |
| попыток | 2 в режиме «Проверить навык», без ограничения в режиме «Научить» | ТЗ ASN05 (стр. 9) |

Начальное состояние — «Назначено». Конечные — «Завершено». Источник — ТЗ ASN06 (стр. 10).

| Из | В | Событие | Кто инициирует |
|---|---|---|---|
| Назначено | В работе | сотрудник ответил на первый шаг | сотрудник |
| В работе | Завершено | последняя попытка принята | система |
| Назначено | Просрочено | наступил срок | система |
| В работе | Просрочено | наступил срок | система |

## Связи

| Связь | Кратность |
|---|---|
| Назначение — Сотрудник (`employee`) | много → 1 |

## Requirements

### Requirement: Режим по умолчанию
Система MUST создавать назначение с режимом «Научить», если автор не выбрал «Проверить навык».
Других значений режима у назначения нет.

**Источник:** ТЗ ASN02 (стр. 6); ТЗ ASN03 (стр. 7)

#### Scenario: Автор не менял задачу
- GIVEN автор открыл форму назначения
- WHEN он выбрал сотрудника и сохранил форму, не меняя задачу
- THEN создано назначение с режимом «Научить»

### Requirement: Лимит попыток по режиму
Система MUST принимать в режиме «Проверить навык» не больше 2 попыток на назначение.

**Источник:** ТЗ ASN05 (стр. 9)

#### Scenario: Третья попытка
- GIVEN назначение в режиме «Проверить навык», сотрудник завершил 2 попытки
- WHEN он начинает третью попытку
- THEN попытка не создана, показан текст «Попытки закончились»

### Requirement: Переходы только по таблице
Система MUST менять состояние назначения только по таблице переходов этой спеки.

**Источник:** решение агента 10.10.2026 — переходы вне таблицы запрещены

#### Scenario: Завершённое не возвращается в работу
- GIVEN назначение в состоянии «Завершено»
- WHEN сотрудник отвечает на шаг
- THEN состояние остаётся «Завершено», ответ не сохранён
