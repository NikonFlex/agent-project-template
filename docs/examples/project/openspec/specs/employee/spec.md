# Сотрудник

## Purpose
Тип: сущность. Сотрудник компании, которому назначают тренажёры. Назначения объявляет спека
`assignment`.

## Сущности

### Сотрудник

| Поле | Значение | Источник |
|---|---|---|
| имя | строка, обязательно | ТЗ EMP01 (стр. 14) |
| почта | уникальна | ТЗ EMP01 (стр. 14) |

Состояний нет.

## Связи

| Связь | Кратность |
|---|---|
| Сотрудник — Назначение (`assignment`) | 1 → много |

## Requirements

### Requirement: Уникальная почта
Система MUST отказывать в создании сотрудника, если сотрудник с такой почтой уже есть.

**Источник:** ТЗ EMP01 (стр. 14); ТЗ EMP02 (стр. 15)

#### Scenario: Повтор почты
- GIVEN есть сотрудник с почтой «anna@example.com»
- WHEN автор создаёт сотрудника с почтой «anna@example.com»
- THEN сотрудник не создан, показан текст «Такая почта уже есть»
