# С-01. Сотрудник проходит проверку навыка

Роль: сотрудник. Релиз: входит.

## Начальное состояние

Анне назначен тренажёр в режиме «Проверить навык»; она завершила 2 попытки.

## Шаги

1. Анна начинает третью попытку. Ожидаемо: попытка не создана, показан текст
   «Попытки закончились».
   Требования: `assignment: Лимит попыток по режиму`
2. Анна открывает список назначений. Ожидаемо: назначение отсортировано по сроку.
   Требований нет.

## Чего нет в спеках

- Шаг 2: порядок списка назначений — источник молчит; вопрос продакту.
