# А-01. Автор назначает тренажёр

Роль: автор. Релиз: входит.

## Начальное состояние

Есть сотрудник Анна с почтой «anna@example.com»; назначений у неё нет.

## Шаги

1. Автор открывает форму назначения. Ожидаемо: кнопка «Назначить» недоступна, в поле
   сотрудника — «Выберите сотрудника».
   Требования: `assignment-form: Сохранение без сотрудника`
2. Автор выбирает Анну и нажимает «Назначить», не меняя задачу. Ожидаемо: создано назначение
   в режиме «Научить».
   Требования: `assignment: Режим по умолчанию`

## Ветви сбоя

1. Автор заводит второго сотрудника с почтой «anna@example.com». Видит: «Такая почта уже есть».
   Требования: `employee: Уникальная почта`
