# Требования (образец)

Образец проекта для `tools/spec_check.py` и `tools/source_check.py`: источник, три спеки,
карта и реестр. Устройство и правила — [openspec/README.md](../../../../openspec/README.md)
корня репозитория; здесь только таблицы, которые читают приборы.
