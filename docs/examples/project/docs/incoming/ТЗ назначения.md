# Техническое задание: назначение тренажёров

## Назначение

ASN01. Форма назначения: поле сотрудника с подсказкой «Выберите сотрудника» и кнопка «Назначить»; кнопка недоступна, пока сотрудник не выбран.
ASN02. Если автор не выбрал режим, назначение создаётся в режиме «Научить».
ASN03. Режимы назначения: «Научить» и «Проверить навык».
ASN04. У назначения может быть срок — дата.
ASN05. В режиме «Проверить навык» даётся 2 попытки, в режиме «Научить» число попыток не ограничено. Когда попытки закончились, показать «Попытки закончились».
ASN06. Состояния назначения: «Назначено», «В работе», «Просрочено», «Завершено». В работу назначение переходит, когда сотрудник ответил на первый шаг; завершается, когда принята последняя попытка; просрочено — когда наступил срок.

## Сотрудники

EMP01. У сотрудника имя (обязательно) и почта; почта уникальна.
EMP02. Сотрудник с почтой, которая уже есть, не создаётся; показать «Такая почта уже есть».

## Вне релиза

EXP01. Выгрузка назначений в Excel.
