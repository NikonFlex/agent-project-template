# Реестр обратной сверки

Строки источника, которые не называет ни требование, ни карта. У строки — номер, её начало
(дословно, по нему прибор видит правку), класс и основание. Проверка — `tools/source_check.py`.

| Класс | Когда | Основание |
|---|---|---|
| служебное | заголовок, оглавление, история версий, пример без правила, повтор соседней строки | что это |
| покрыто | содержание есть в требовании со ссылкой на соседнюю строку | адрес требования в обратных кавычках |
| вне объёма | README или сам источник выносят это за релиз | строка README («Границы релиза») |

Строка с поведением, данными, правами, текстом или ограничением, которых нет ни в одном
требовании, сюда не идёт: она становится требованием. «Тема упомянута» не значит «покрыто».
Правка текста строки в источнике снимает её запись — прибор покажет её как изменившуюся.
